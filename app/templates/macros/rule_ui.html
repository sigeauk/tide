{# Shared rule-UI macros. state_badge(state) — the four lifecycle states of a rule, defined by where it currently exists across the tenant's SIEM spaces (used to migrate rules from one SIEM to another: analysts keep working on staging — the old production — until the migration lands): Production = only in a production space Staging = only in a staging space Migrated = in BOTH (a linked staging + production pair) Deprecated = in NEITHER (not found at the last successful sync) Only Migrated and Deprecated are BADGED — Production and Staging are already shown by the SIEM pill. Used by the rule card, the table row and the rule modal so they always agree. #} {% macro state_badge(state, title='') -%} {#- state is 'Linked' (this rule has at least one entry in its Linked panel), 'Deprecated', 'SIEM offline' (its SIEM failed the check before the last sync; title carries the reason), or '' for a plain standalone rule, which renders nothing -- its destination name (the SIEM pill) already says where it is. -#} {%- if state in ['Linked', 'Deprecated', 'SIEM offline'] -%} {%- set meta = { 'Linked': 'Linked — see the Linked panel in the rule window for the other copy', 'Deprecated': 'Deprecated — not found in the SIEM at the last successful sync', 'SIEM offline': 'SIEM offline — its SIEM could not be reached before the last sync' } -%} {%- set css_state = {'Linked': 'migrated', 'Deprecated': 'deprecated', 'SIEM offline': 'offline'}[state] -%} {{ state }} {%- endif -%} {%- endmacro %} {% macro upstream_badge(up, only_news=false) -%} {#- The Elastic or Sigma rule a rule came from (rule_origins.statuses): its source, and unless it is up to date, its state. ``only_news`` shows it only when there is something to act on (an update available, or retired upstream): the rule card. Nothing for the tenant's own rules. -#} {%- if up and (not only_news or up.state in ['update', 'retired']) -%} {%- set cls = {'update': 'info', 'current': 'success', 'retired': 'warning', 'removed': 'muted'}[up.state] -%} {{ up.source }}{% if up.state != 'current' %} · {{ up.label }}{% endif %} {%- endif -%} {%- endmacro %}
