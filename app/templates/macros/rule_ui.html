{# Shared rule-UI macros. state_badge(state) — the four lifecycle states of a rule, defined by where it currently exists across the tenant's SIEM spaces (used to migrate rules from one SIEM to another: analysts keep working on staging — the old production — until the migration lands): Production = only in a production space Staging = only in a staging space Migrated = in BOTH (a linked staging + production pair) Deprecated = in NEITHER (not found at the last successful sync) Only Migrated and Deprecated are BADGED — Production and Staging are already shown by the SIEM pill.
